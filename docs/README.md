# AgriSureGIS Documentation

This directory contains system design documents, diagrams, requirements, and guides for the AgriSureGIS parametric insurance assessment platform.

## Contents

- Relational schemas, ERDs, and spatial query architectures.
- Product requirements and design assets.
- System architecture diagram (`system architecture.png`), showing the three-tier design: Presentation Layer (React/Leaflet), Web-GIS Application Layer (FastAPI + GeoServer for spatial layer serving), and Database Layer (PostgreSQL/PostGIS).
